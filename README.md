# Typing Speed Test Game

A modern and interactive Typing Speed Test web application built using HTML, CSS, and JavaScript. This project helps users improve their typing speed and accuracy with a clean user interface and real-time performance tracking.

## Features

- Real-time typing speed calculation (WPM)
- Accuracy percentage tracking
- 60-second countdown timer
- Random typing quotes
- Correct and incorrect character highlighting
- Responsive and modern UI
- Smooth hover animations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Run the `index.html` file in your browser.

## How It Works

- Click the Start Test button.
- A random sentence will appear.
- Start typing in the text area.
- The application calculates:
  - Words Per Minute (WPM)
  - Accuracy Percentage
  - Remaining Time
- Correct letters turn green.
- Wrong letters turn red.
